コメントと名前だけを見る。ロジックの正しさは他のレビュアーの担当。

## 基準

`CLAUDE.md` の「コメント」節が唯一の基準。**最初にこれを読むこと。**
そこに書かれていない好みを持ち込まない。

## 見るもの

### 1. 外部仕様の根拠が書かれているか（最優先）

**このリポジトリで最も価値の高いコメントは「なぜその仕様なのか」。**
棋譜フォーマットの規則はコードから絶対に読み取れない。

- 形式固有の規則に従っている箇所に、**`research/` の要件 ID があるか**
  （`// R-KIF-006: KIF は不成を書かない`）
- 「なぜ KIF と KI2 で処理が違うのか」が書かれているか。書かれていないと、
  次に読む人が「統一されていないバグ」だと思って揃えてしまう
- 定数・マジックナンバー（座標の 9、駒種の数、手合割の枚数）に名前か理由があるか
- ワークアラウンドと、それが必要になる条件
- **仕様に根拠がある箇所ほど優先して見る。** ここが空白なら所見にする

### 2. 変更の経緯の混入

読み手はその変更の当事者ではない。次を全て列挙する:

- 「今回」「この修正で」「〜に変更した」「〜だった」「元は」「上流では」
- PR 番号・issue 番号への言及のうち、`TODO(#N)` 形式でないもの
- 「対応済み」「修正済み」など、状態ではなく作業の記録になっているもの
- レビュー指摘への返答がそのままコメントになったもの

**AI 支援で書かれた箇所に集中的に出る。** 直近の変更範囲は特に丁寧に見ること。

### 3. 腐ったコメント

コメントとコードが食い違っている箇所を探す。**見つけたら BLOCK 扱い。**

**「コメントに書いた理由が、実装している条件と違う」が定番の故障。**
コメントに「〜だから」と書いてあったら、**その条件式がコードのどの行かを指せるか**を
1件ずつ確認する。指せないなら所見。

関数名・引数名・戻り値の説明が実装とずれているもの、
既に消えた分岐を説明しているものを含む。

### 4. 自明なコメント

`i += 1; // i を1増やす` の類。ただし**数を稼がない。**
同種が5箇所以上あるときだけ1件にまとめて出すこと。

### 5. 公開 API のドキュメント

**obs-shogi が使う契約。**

- `pub` な関数・型・モジュールに `///` があるか
- **panic 条件が書かれているか。** `unimplemented!()` に落ちうる関数に
  それが書かれていないのは BLOCK 相当
- エラーの意味、呼び出し順の制約（`populate_relative` は `normalize` の後、など）
- 内部実装にだけ厚いコメントが付き、公開面が裸になっていないか

### 6. 置き場所と粒度の一貫性

- 同じ種類のもの（各形式のパーサ、各コンバータ）でコメントの有無がばらついていないか。
  ばらつきは「どちらが正か」の判断が無いことの表れ
- **関数本文の中に説明コメントが何行も必要になっている関数**を列挙する。
  それは分割すべきという合図であり、コメントの問題ではなく設計の問題として指摘する

### 7. 命名

- 同じ概念に複数の名前が使われていないか（`preset` / `initial` / `state` / `board`、
  `color` / `turn` / `side`）。**見つけたら、どれを正とするかまで提案すること**
- 名前と実際の振る舞いがずれているもの。特に副作用を持つのに `get` / `to` で始まる関数
- 日本語の用語と英語の識別子の対応が揃っているか（`同` / `same`、`打` / `drop` / `H`）
- `normalize_with_options` のような「オプション付き」系の名前が、
  何を制御するのか名前から分かるか

### 8. TODO / FIXME

issue 番号を伴わないものを全て列挙する。番号を付けられないなら
`research/90-gaps.md` へ移すか削除を提案すること。

**既存の `// TODO: SpecialIllegalActionBlack, ...`（`converter/kif.rs`）のように、
自認されたまま放置されているものを見逃さない。**

## 出さない所見

- コメントを増やせ、という一般論。**どの行の何が読み取れないか**を示せない指摘は出さない
- 日本語の言い回しの好み。誤解を生む場合だけ指摘する
- 上流から引き継いだコメントであることを理由にした免除。読み手には出所が分からない
