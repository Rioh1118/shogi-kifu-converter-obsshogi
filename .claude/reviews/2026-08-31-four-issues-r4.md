## 所見

### R4-18 [BLOCK] CSA のコメントの空の断片が裸の `'` を書き、そこから先の手が消える

- 場所: `src/converter/csa.rs` `write_comment`
- 指摘: robustness
- **ラウンド3の修正（コメントを改行でも割る）が持ち込んだ。** `main` は読めていた
- 実測: `comments: ["感想\n"]` の3手 → `to_csa` → `parse_csa_str` = **`Ok`、1手**。
  `"a\n"` / `"a,"` / `",a"` / `"a\r\nb"` / `""` がすべて同じ形
- テキストボックスに書いたコメントは末尾に改行が付くのが普通で、`\r\n` も来る
- 直した: 空の断片に行を与えない。KIF / KI2 が裸の `*` を書くのは、そこでは読み戻せるから

### R4-01 [HIGH] 注記の印まで「改行の代わり」として飛ばし、注記付きの棋譜を落とす

- 場所: `src/parser/kakinoki.rs` `begins_the_line_below`
- 指摘: comment
- **ラウンド3の修正が持ち込んだ。** 実測（いずれも `main` は `Ok`）:
  `（まで先手良し）` / `※ 3 分の1` / `[ 3 分]` / `※ 12 手目からの変化` が **`Err`**
- KIF の行形には `まで…` と番号付き行があり、**どちらも注記が印の後ろで普通に開く**
- 直した: 飛ばす1文字を「注記が開く印ではないもの」に限る（`NOTE_MARKERS`）。
  読み手ごとに述語を持つ必要も消え、`LineShapes` は2本に戻った

### R4-06 [HIGH] CSA のヘッダ値が単独の `\r` を割らず、空になる値で `N+` だけの行を書く

- 場所: `src/converter/csa.rs` `write_header_value`
- 指摘: rust / spec
- `str::lines()` は `\r` を行末と見ない。`{"先手":"山田\r太郎"}` も `{"棋戦":"\n"}` も
  **書けて、そのファイルが全体 `Err`**
- 直した: 行末の集合を `LINE_ENDS` に1本化して3つの書き手が共有。潰した結果が空なら行ごと書かない

### R4-13 [MEDIUM] 手合割の語彙が読み手と `is_a_known_name` でずれ、`その他` で読めないファイルを書く

- 指摘: spec
- 実測: `{"header":{"手合割":"その他"},"initial":{"preset":"HIRATE"}}` → 盤面の無い
  `手合割：その他` だけ → 読み直すと `Err`
- 直した: `その他` を `handicap` 側の定数にして読み手と書き手が引く

### R4-07 / R4-19 [MEDIUM] KI2 の分岐ヘッダのエラーが、行も原因も取り違える

- 指摘: rust / robustness
