# KI2

**KI2 の一次仕様は見つからなかった。** 柿木の KIF 文書は KI2 に触れていない。指し手は伝統形式（20-notation.md）に従うものとして扱う。
JKF README の比較表では KI2 は「元座標: 要相対逆算」「手番: あり」「消費時間: なし」。

ここの規定は全て**資料なし**で、コードの引用から推定した。

- **R-KI2-001**（3箇所で引用）ヘッダと局面図は KIF と共通。確信度 低
- **R-KI2-002**（3箇所）指し手は手番記号つきで1行に複数並べられる。確信度 低
- **R-KI2-003** 相対位置を使っても1手に決まらない手は書き出さない（`UnspellableMove`）。書けば、このクレート自身が読み戻せない。確信度 低
- **R-KI2-005** 印刷上の表記: 飛・角の「上」を「行」、「不成」を「生」と書くものも読む。確信度 低
- **R-KI2-006** 終局の書き方は資料に定めが無い。このクレートは `まで<N>手で<句>` を使う（D5 で tsshogi に合わせた）。確信度 低
- 拡張子 `.ki2`（Shift_JIS）と `.ki2u`（UTF-8）の対応も資料に無い
