- **GAP-034**（解消）KI2 の詰みの句 `まで61手で詰`・`まで61手詰` を読めない（Kifu-for-JS の3ファイル、tsshogi）。`まで2手で不詰` は読める
- **GAP-035**（解消。D28）封じ手を読めない。KIF の `  53 封じ手`（名人戦の公式の棋譜）と KI2 の `まで2手で封じ手`。R-KIF-007 の語彙に無いが、実際の棋譜と tsshogi・Kifu-for-JS は読む。JKF にも CSA にも対応する語が無い
- **GAP-036**（解消）改行が `\r\r\n` の KIF を1行目で止める
- **GAP-037**（解消）半角数字の移動先を読めない。KI2 の `▲26歩`、KIF の `1 76歩(77)`。tsshogi は読む
- **GAP-038**（解消）KIF の `同銀　(79)`（駒名の後ろに全角空白）を読めない。`同　銀(79)` と `同銀(79)` は読める
- **GAP-039**（解消）枠の行（`  ９ ８ ７…` と `+---+`）の無い KIF の盤面図を読めない（「持駒を書いているのに盤面が無い」になる）。tsshogi は読む

- **GAP-041** CSA V3.0 を読めない。`'CSA encoding=` の行、`+7776FU,T0`、`$TIME:`、`'*` のコメント、`%MAX_MOVES` のどれか1つで全体が `failed to parse`。CSA V3.0 の仕様書にある例のファイルも読めない。外部の `csa` クレート
- **GAP-042** EUC-JP の CSA を読めない（`Decode Error`）。consumer は自前で EUC-JP を試している

### 読めるが、中身が黙って変わる・消える

- **GAP-050**（解消。GAP-024 も同時に解消）KI2 の行の途中の `▽３四歩`（`▼`・`☗`・`☖` も）を、拒まずに黙って捨てる。1手少ない記録が `Ok` で返る。tsshogi は6種の記号を読む

- **GAP-043** KI2 の終局句が名指す側を読まない。`まで2手で後手の反則負け`（後手が負け）を、手番の先手が負けた `ILLEGAL_MOVE` と読む。`まで2手で先手の勝ち` も手番の先手が投了した `TORYO`（後手の勝ち）と読む。勝者が入れ替わる
- **GAP-044** CSA のコメント（`'` の行）を全て捨てる。書き手は書いているので、CSA で保存して開き直すとコメントが全て消える。floodgate の `'** 評価値 読み筋` も消える。外部の `csa` クレート
- **GAP-045** CSA の行の中のコメント（`%KACHI,'* -5000 win`）で、そこから先を黙って捨てる。終局が消える。外部の `csa` クレート（GAP-012 と同じ根）
- **GAP-046** CSA の日時を書き換える。`$START_TIME:2014/10/14 01:15:29` が `2014/10/14 1:15:29` になる。外部の `csa` クレート
- **GAP-047** CSA の書き手が、置き場のある 開始日時・終了日時・持ち時間（`$START_TIME`・`$END_TIME`・`$TIME_LIMIT`）を書かない。CSA で保存すると消える
- **GAP-048** CSA に書くと変化が全て消える。CSA に変化の書き方は無いので消えること自体は避けられないが、`Ok` のままで呼び手に知らせない
- **GAP-049** ヘッダの値の改行を、区切りを入れずに詰める（`1行目2行目`）。語がつながる
