# KIF

出典: 柿木義一「棋譜ファイル KIF 形式」2024/08/02 版 http://kakinoki.o.oo7.jp/kif_format.html （以下 KIF §n）

- **R-KIF-001** 文字コードは `.kif` が Shift_JIS、`.kifu` が UTF-8。改行は OS の標準。BOM については**資料に無い**（このクレートは取り除く。GAP-006）。〔KIF §2〕確信度 中
- **R-KIF-002** `#` で始まる行はどこにあってもよいコメント。空行は**資料に無い**。〔KIF §4〕確信度 高
- **R-KIF-004** ヘッダは `<キーワード>：<値>` の1行。キーは標準の語に加えて利用者が任意に足せる。値の中の改行を表す方法は無い。〔KIF §6・§7〕確信度 高
- **R-KIF-005** 指し手の文法 `[<手番>]<移動先><駒>[<装飾子>]<移動元>`。移動元は `(11)`〜`(99)`。`(00)` は文法外。〔KIF §9〕確信度 高
- **R-KIF-006** 打ちには必ず「打」を付ける。「不成」は書かない。〔KIF §9「打つ場合は、必ず「打」を付ける」「不成の場合は、「不成」を表記しない」〕確信度 高。**伝統形式と逆**（R-NOT-003 / R-NOT-005）
- **R-KIF-007** 終局の語は 中断・投了・持将棋・千日手・切れ負け・反則勝ち・反則負け・入玉勝ち・不戦勝・不戦敗・詰み・不詰 の12語。〔KIF §9〕確信度 高
  - 反則勝ち＝「直前の指し手が反則」（手番側の勝ち）。反則負け＝「その指し手の手番側が反則で負け」
  - 不戦勝・不戦敗は「先手（上手）の」と書かれているが、同じ節で「▲：先手（下手）」とも書かれており、**資料自身が食い違う**（99-sources 9.2-11）
- **R-KIF-008** 消費時間は指し手と同じ行に `( 分:秒/時:分:秒)`（1手／累計）。省略できる。分の上限と桁揃えは**資料に無い**。〔KIF §10、§3 の例〕確信度 高
- **R-KIF-010** `*` で始まる行は直前の指し手へのコメント。初手の前のコメントは開始局面のコメント。〔KIF §12〕確信度 高
- **R-KIF-011** `&` で始まる行はしおり。〔KIF §13〕確信度 高
- **R-KIF-012** 見出し行 `手数----指手---------消費時間--` は無くてもよい。〔KIF §3〕確信度 高
- **R-KIF-014** 局面図（盤面図）の書式（1行9升、後手の駒は `v`、持駒行、`なし`、手番行「後手番」）。**一次資料なし**（§11 は局面図が付くことだけを書く）。コードと二次資料（Kifu for Windows の出力の観察）による。確信度 中

資料に無いもの（読むときの判断は 95-decisions へ）: `変化：N手`（分岐）の書式、`まで○手で…` の要約行、終局語の後のコメントの帰属、手番記号の異体、「王」。
